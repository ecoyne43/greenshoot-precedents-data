# Greenshoot precedents data

The library behind Groundworked Precedents. `precedents.json` holds every precedent (`{ "records": [...] }`).
The app commits here each time someone approves an inbox item or edits a record, so the history shows who changed
what. Images live in Netlify Blobs, not here. Edit by hand only if you know what you're doing; the app is the normal
way in.
